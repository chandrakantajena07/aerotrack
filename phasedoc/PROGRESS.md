- 2026-10-15T00:00:00Z — Arc opened. Decided (user-confirmed) to build an original, standalone codebase instead, inspired by worldmonitor's dark live-intel visual style, powered by the free public adsb.lol ADS-B feed. Seeded 17 tasks across phases P0-P4. Plan, architecture, resources, and explainers documents written. Cockpit starting next on :7901 (shared cockpit.mjs codebase from the RoboLab 3D arc, parameterized via env vars — not forked).
- 2026-10-15T11:26:00Z — P0-P2 complete. Default view set to Western Europe (busy airspace) since the data source is radius-capped at 250nm per query — a world-zoom start showed misleadingly few aircraft. Moving to GitHub + Vercel.
